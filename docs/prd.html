1. Visão geral

Creatorfy é uma plataforma de apuração de comissão e análise de desempenho para creators de afiliado do TikTok Shop, operada por uma agência (matriz) que gerencia múltiplos creators. Cada creator importa seus pedidos de afiliado — via a API do TikTok Shop Affiliate ou por planilha — e a plataforma calcula a comissão por turno de live e gera relatórios exportáveis.

2. Principais recursos

  • Importação de pedidos de afiliado — automática via API (Search Creator Affiliate Orders, escopo 1021508) e manual via arquivo .xlsx.
  • Fechamento de comissão por turno — apura a comissão do creator por janela de data/hora (turno), atribuindo cada pedido à live/creator correta.
  • Relatórios — exportação por creator em imagem/PDF.
  • Dashboard — análise das lives (GMV, comissão, pico por hora).
  • Multi-creator / agência — a matriz convida creators e vê tudo consolidado; cada creator acessa apenas os próprios dados.

3. Fluxo de dados

Creator autoriza (fluxo OAuth de Creator do TikTok Shop Affiliate)
  -> token (access/refresh) armazenado no servidor (criptografado, service role)
  -> "Sincronizar": Search Creator Affiliate Orders (requisição assinada HMAC-SHA256)
  -> pedidos de afiliado mapeados para o modelo interno (orders), por creator
  -> Fechamento (apuração por turno) e Dashboard (análise das lives)
  -> Relatório de comissão (imagem/PDF)

Alternativa manual: o creator exporta a planilha de pedidos de afiliado no TikTok Shop e faz upload — mesmo destino (orders).

5. Casos de uso

  • Creator conecta a conta TikTok, sincroniza os pedidos e vê seu fechamento de comissão por turno; baixa o relatório.
  • Agência (matriz) gerencia os creators, acompanha a comissão consolidada e a atividade de cada um.
  • Apuração por turno de live quando vários creators se revezam na mesma conta/live.

6. Segurança e privacidade

  • Tokens OAuth apenas no servidor (variáveis de ambiente + service role); nunca no cliente.
  • Isolamento por usuário (RLS) no banco: cada creator acessa somente os próprios dados; a matriz (admin) acessa o consolidado.
  • Aprovado na avaliação de segurança de dados do Brasil.
  • Escopo mínimo — apenas os escopos de Affiliate necessários.

7. Escopo do serviço

Creators de afiliado locais do Brasil (BR).
