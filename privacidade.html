Politica de Privacidade

Ultima atualizacao: 22 de maio de 2026

A SPACEHUB AI, de titularidade de Vanessa Pachalki, se compromete a proteger a privacidade dos usuarios de sua plataforma, em conformidade com a Lei Geral de Protecao de Dados (LGPD — Lei 13.709/2018).

2. Como Usamos os Dados

  • Autenticacao: Usamos o e-mail do Google para verificar se o usuario esta autorizado a acessar a plataforma.
  • Processamento de pedidos: Os dados das planilhas XLSX sao parseados no navegador (client-side) e armazenados no banco de dados para gerar dashboards e calculos de comissao.
  • Isolamento por agencia: Cada agencia tem seus dados completamente isolados. Nenhuma agencia acessa dados de outra.
  • Auditoria: Registramos tentativas de login bloqueadas para seguranca.

4. Armazenamento e Seguranca

  • Banco de dados: Supabase (PostgreSQL hospedado na AWS, regiao us-east-1), com criptografia em repouso e em transito.
  • Row Level Security (RLS): Politicas de seguranca a nivel de linha em todas as tabelas, garantindo isolamento por agencia e por usuario.
  • Autenticacao: Google OAuth 2.0 via Supabase Auth — nao armazenamos senhas.
  • Transmissao: HTTPS/TLS em todas as conexoes.
  • Codigo-fonte: Ofuscado em producao para protecao de propriedade intelectual.

5. Compartilhamento de Dados

Nao vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins comerciais.

Seus dados podem ser acessados apenas por:

  • O administrador da sua agencia (dados de performance e pedidos)
  • A administradora da plataforma (Vanessa Pachalki), para suporte tecnico e manutencao
  • Supabase (subprocessador), para armazenamento e processamento — sujeito a sua propria politica de privacidade

6. Retencao de Dados

  • Dados de pedidos e uploads sao mantidos enquanto a conta da agencia estiver ativa.
  • Apos a exclusao de uma conta, os dados sao removidos em ate 30 dias.
  • Logs de tentativas de login sao mantidos por 12 meses.

7. Direitos do Titular (LGPD)

Voce tem direito a:

  • Acesso: Solicitar copia dos seus dados pessoais
  • Correcao: Solicitar correcao de dados incompletos ou incorretos
  • Exclusao: Solicitar a eliminacao dos seus dados pessoais
  • Portabilidade: Solicitar a transferencia dos seus dados para outro servico
  • Revogacao: Revogar seu consentimento a qualquer momento
  • Informacao: Saber com quem seus dados foram compartilhados

Para exercer qualquer desses direitos, envie um e-mail para: privacidade@spacehub-ai.com

8. Cookies e Armazenamento Local

  • Cookies: A plataforma utiliza cookies de sessao do Supabase Auth para manter a autenticacao. Nao utilizamos cookies de rastreamento ou publicidade.
  • SessionStorage: Utilizado para cache de dados (TTL de 5 minutos) e configuracoes de tenant. Limpo automaticamente ao fechar o navegador.
  • LocalStorage: Utilizado apenas para preferencia de tema (dark/light/auto). Nao contem dados pessoais.

9. Processamento Client-Side

As planilhas XLSX enviadas pelo usuario sao processadas inteiramente no navegador (client-side) usando a biblioteca XLSX.js. O arquivo original nao e enviado para nenhum servidor — apenas os dados parseados sao armazenados no banco de dados.

10. Transferencia Internacional

Os dados sao armazenados em servidores da AWS (via Supabase) localizados nos Estados Unidos. Esta transferencia e realizada com base no Art. 33, II da LGPD (clausulas-padrao contratuais).

11. Menores de Idade

A plataforma nao e destinada a menores de 18 anos. Nao coletamos intencionalmente dados de menores.

12. Alteracoes nesta Politica

Esta Politica pode ser atualizada periodicamente. Alteracoes significativas serao comunicadas por e-mail ou pela Plataforma. A data da ultima atualizacao esta indicada no topo deste documento.
